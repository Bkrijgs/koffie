# Static assets

Bestanden in deze map zijn bereikbaar onder de root van de site.

Bv. `public/barista.svg` → `/barista.svg`.

## Barista-icoon

- Drop een SVG als `public/barista.svg` (aanbevolen — schaalt + kleurt mee
  als het pad `currentColor` gebruikt).
- Of een raster als `public/barista.png`.

Daarna wijs ik `components/Barista.tsx` aan dit pad.
